## 1. Write plan：制定计划及确认需求

### 1.1 用户指定的目标

在现有 `magmc2/src` 和 `magmc-doc/doc/magnetar.typ` 框架下，依据英文 `magmc-doc/doc/lll.typ` 修改电子／光子散射：

- 采用有限磁场背景中的电子—光子散射振幅。
- 只保留树级的 `s`、`u` 两个通道，先相干求和，再计算概率。
- 电子外腿为最低朗道能级：`n_i = n_f = 0`。
- 内部电子传播子保留 `n = 0, 1`，包括这些能级允许的全部磁矩自旋态及正、负能态。
- 保留有限场反冲、任意入射方向和完整入射 Stokes 信息。
- 暂不加入偏振传播中的散射选择性消光。
- 出现文档无法确定的问题时，应停止并向用户确认。

此处实现的是**指定朗道能级截断下的有限场 QED 模型**，不是全朗道能级、全微扰阶数的 QED 结果。按 `lll.typ`，共振采用自旋分辨自然线宽，因此也不是共振处未经正则化的裸树图计算。

### 1.2 最初进行的只读检查

最初处于 Plan Mode，先阅读和检查环境，没有立即修改代码：

- 检查仓库状态、构建文件和目录约束；当时 `magmc2` 工作区干净，最新提交为 `1bce83f`。
- 阅读 `lll.typ` 的物理约定、旋量、顶点、传播子、自然线宽、截面归一化、适用域、概率条件化及建议代码接口。
- 核对 `magnetar.typ` 中的 Stokes 符号、偏振基底旋转、电流闭合、测地线和旧共振逃逸条件。
- 检查原散射、分布、偏振、初始化、输运、积分、随机数及输出代码。
- 确认本地有 `g++-16` 和既有 GSL／HDF5／HighFive 构建环境。

检查发现，原散射代码使用 δ 共振近似，只选择离散共振速度；出射能量没有 LLL 反冲因子，出射偏振随机投影为 O/E 模式。原候选事件架构可以保留，但其微观核、速率、靶粒子选择和出射采样必须一起更换。

### 1.3 向用户提出并获得答复的决策

文档要求，当完整速度支撑不满足完整出射角域的适用条件时显式报告错误。原批处理则捕获单光子异常后继续运行，因此询问了错误处理方式。

**用户选择：记录失败光子并继续。**

据此决定：

- 适用域失败终止当前光子，不终止其余光子的处理。
- 保留 `n_failed` 总计数，并单独记录物理适用域失败。
- 不通过截断速度分布或删除出射角域修补物理适用域错误。

### 1.4 提交的实施计划

随后提交完整计划，并由用户明确要求实施。计划主要包含：

1. 独立实现线宽、微分 Jones 核、角响应和局部速率响应。
2. 使用统一复振幅构造光深、碰撞条件速度分布及出射角分布。
3. 保留候选事件稀释法，用最大响应本征值构造偏振无关包络。
4. 出射能量使用 LLL 反冲，出射偏振保存为完整 Stokes。
5. 禁用旧 δ 共振逃逸捷径，传播到表面吸收或数值外边界。
6. 增加适用域失败分类、独立 QED 输出文件和元数据。
7. 编译两个入口，完成微观、数值、采样、输运和收敛验证；不启动原有亿级生产任务。

### 2.2 微观核

依据 `lll.typ` 实现：

- 单位归一化的四分量外场旋量和各分量对应的振子阶数。
- `I00`、`I10`、`I01` 重叠积分，包括导引中心复相位。
- 两个通道以及所有保留虚态的复振幅求和。
- 正、负能态的因果分母符号；`n=0` 宽度为零，`n=1` 使用各自旋自然线宽及纵向运动的时间膨胀因子。
- 自然线宽的一维正积分，而不是人为指定常数宽度。
- 稳定形式的 LLL 反冲能量，以及最终电子纵向动量、能量和反冲 Jacobian。
- 长度单位为 cm 的 Jones 核 `M = r_e sqrt(y / (x J_r)) T`，以及便于数值积分的 `M/r_e`。
- `rho_out = M rho_in M† / tr(M rho_in M†)`，继续使用本项目 `V = 2 Im(rho_12)` 的约定。

生产代码通过反向有效磁场坐标处理正电子。另在测试中写了直接正电荷旋量和顶点构造，用于独立核对该映射；没有再次反转 `NegateDist` 已经带符号的速度分布。

### 2.3 速率与采样

已实现的事件链路为：

1. 由现有电流闭合得到种群密度因子。
2. 检查所有有密度种群的完整速度支撑。
3. 对每个试探速度做沿实际磁场的洛伦兹变换。
4. 积分同一个 `M†M` 得到角响应，再积分连续速度得到速率响应 `K`。
5. 用 `Lambda = lambda_max(K)` 积分候选光深。
6. 将真空偏振推进到候选位置，以 `tr(K rho)/Lambda` 接受候选。
7. 接受后，按实际碰撞率选择种群，并反演该种群的碰撞条件速度 CDF。
8. 依次反演出射极角边缘 CDF 和条件方位角 CDF。
9. 计算反冲、出射密度矩阵和逆洛伦兹变换，重建轨道平面及新的屏幕 Stokes。

保持原负残余候选光深 `tau = log(U)` 的约定。这里的候选光深不同于实际偏振相关的物理散射光深。

响应矩阵内部保存两个对角元及复非对角元的实、虚部，而不是只保存 `s0` 和 `sQ` 后相减。这样避免弱 E 模式速率来自两个接近的大数之差。

### 2.4 与原输运框架的连接

修改 [`src/evolution.hpp`](../src/evolution.hpp)：

- `Basis` 增加实际光子方向和两条屏幕基矢。
- 对精确轴向入射统一选择屏幕基底，避免丢弃 U/V。
- 散射速率使用直接几何求值；真空偏振传播仍可使用原有几何／真空系数缓存。
- 每个 `PhotonEvolution` 持有自己的散射对象副本，避免多线程共享可变缓存。

- 外边界通过 `Geodesic::Options` 暴露给演化选项，默认仍为 `10^5 R_*`。
- 保持碰撞发生在边界之前时先处理碰撞的顺序。
- 在逃逸记录前，将仍为绝热标签的偏振转换成当前屏幕的 Stokes，避免读取过期或初始零三元组。
- 增加可选进度回调；命令行 `--trace` 可输出轨迹推进位置。

## 3. 数值实现与迭代修正

### 3.1 积分和误差传递

- 新核采用正权重的 Gauss–Kronrod 15/7 规则及周期方位角积分。
- 嵌套积分不共享 GSL 工作空间，并向外层传递内层误差估计。
- 积分主要在约化截面尺度上进行，避免直接对约 `10^-25 cm²` 的量套用不合适的绝对容差。
- 后续将最初的逐区间相对精度控制改为**整个积分的累计误差控制**：所有正权重区间及其误差仍保留在总和中，不再对每个极小尾部单独追求同样的相对精度。
- 原 [`src/quad.hpp`](../src/quad.hpp) 也改为检查非成功 GSL 状态，而不仅检查结果是否有限。

### 3.2 窄共振与条件 CDF

- 使用有限磁场共振条件寻找速度峰中心，处理两个根、合并根和支撑端点。
- 同时解析两个自旋线宽，保留非共振背景和共振翼。
- 加入精确的 `beta = center + scale sinh(t)` 变量变换；仍在每个积分节点计算完整的真实振幅和线宽。
- 保存积分面板的变量变换信息，使速度 CDF 反演与其归一化使用一致的积分坐标。
- 路径分割考虑速度支撑端点的共振进入／离开，以及相切和转折位置。
- 对 `Boltzmann` 增加积分节点提示，对 `NegateDist` 反射这些节点；节点用于解析分布，并不删除分布尾部。

### 3.3 方位角计算的精确复用

保留直接谱求和实现作为核对基准，同时增加 `AzimuthKernel`：

- 固定出射极角后，去除导引中心相位的顶点只有有限的方位角谐波。
- 通过三个直接谱求和点恢复这组有限谐波系数。
- 积分节点仍计算完整的通道相位和 `M†M`，没有做磁场、能量或入射角参数表插值。
- 与直接振幅在多个磁场、入射方向、出射方向和两种电荷下逐点比较，并检查条件输出 Stokes。

对话中的同一局部速率测试，早期约需 2.6–2.8 秒；此后约为 0.19–0.28 秒。该数字只是特定局部测试的计时，不能当作完整模拟吞吐量。

### 3.4 弱磁场尾部与浮点下溢

完整轨迹曾暴露 `QED periodic azimuth quadrature exhausted`：高斯重叠极小时，相对精度要求与浮点下限、方位角振荡共同导致积分失败或过度耗时。

为此进行了以下修正：

- 用覆盖全部方位角的振幅上界识别表示范围以下的贡献，而不是把少量零采样点当成零积分。
- 用有限谐波系数的三角不等式及 Cauchy–Schwarz 构造方位角尾部误差上界，并把该上界传到外层积分。
- 增加 `bound_azimuth_tails` 选项；可以关闭以进行显式尾部积分对照。
- 增加绝对速率误差预算 `rate_atol = 10^-30 km^-1`。仅在完成适用域检查、完整角域上界及速度积分后，上界足够小时返回带误差的数值零。
- 该误差保存在 `LocalRateResponse.negligible_bound` 及响应误差中，路径积分使用相应的绝对误差预算。
- 设置 `rate_atol = 0` 可关闭这一数值处理。它不是“没有共振所以逃逸”的物理判断，也不会停止轨迹传播。

上述上界和积分误差不是对遗漏朗道能级或其他遗漏物理过程的误差估计，也不应表述成整个模拟的严格区间算术证明。

当前默认数值设置如下：

| 选项 | 默认值 |
| --- | ---: |
| `width_rtol` | `1e-9` |
| `angular_rtol` | `1e-7` |
| `speed_rtol` | `1e-6` |
| `path_rtol` | `1e-6` |
| `rate_atol` | `1e-30 km^-1` |
| `max_panels` | `8192` |

## 4. 适用域、失败策略和输出

### 4.1 适用域

非零密度计算检查完整出射球面条件：

`C = 2x + x²(1 - mu_i²) < 8`。

有限速度区间利用端点检查覆盖整个区间。对于速度趋近光速的尾部，非共向轴向情形会出现无界的静止系光子能量，因此报告适用域错误。精确共向轴向的尾部则有 `x -> 0`，代码和测试对这一例外单独处理，没有一概拒绝所有无限速度尾部。

零电流或零种群份额可以得到零速率。核仅接受单位电荷、电子质量的轻子；没有实现离子的任意质量缩放或独立零平均速度密度种群。

### 4.2 失败分类

引入四类错误：

- `invalid-input`：输入非法。
- `pair-domain`：超出采用的完整角域适用条件。
- `density-closure`：密度／电流闭合不成立。
- `numerical-convergence`：积分、包络、CDF 或其他数值计算不收敛。

主程序对单光子异常记账后继续；配置及存储层面的任务错误仍可终止任务。适用域错误信息包含局部参数和速度支撑，便于定位失败。

### 4.3 HDF5 与日志

修改 [`src/result.hpp`](../src/result.hpp) 和 [`src/main.1.cpp`](../src/main.1.cpp)：

- 保留 `n_failed`，增加其子集计数 `n_domain_failed`。
- 保留既有光子记录字段，包括能量、方向、散射次数和 Q/U/V。
- 新默认输出：`data/output_qed_lll.h5`。
- 新默认错误日志：`data/error_qed_lll.log`。
- 输出写入核版本 `lll-n01-st-width-v1`、数值容差、外边界、场和源参数、种群份额等元数据。
- 续跑时检查这些元数据，避免与不兼容结果混合；旧模型的 `data/output.h5` 未被用作本次新核输出。

只运行了测试用 HDF5 写入和回读，没有启动原批处理的亿级生产模拟。

这里的 29,542 是检查／断言计数，包含随机候选循环中的检查，不是 29,542 个独立物理基准。`Angular response` 输出的是内部 Hermitian 表示的第一个对角元，采用约化截面单位；`Local response` 输出的是该测试的局部包络速率。

GCC 在 HighFive 外部头文件中报告过 `-Wuninitialized` 警告。构建继续完成，HDF5 测试通过；本次没有修改该外部库。
