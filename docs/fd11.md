# FD11 Figure 7–20 原始数据

`src/fd11.cpp` 使用本仓库现有数值模块生成等光子数权重的蒙特卡洛样本。
输出是逐光子数据；能量/方向分箱、观测几何变换、相位平均及绘图由后处理完成。
小规模验证只检验程序行为，不代表与论文图形已达到统计一致。

## 编译和输入磁场表

从仓库根目录执行：

```bash
make fd11
build/fd11 --help
```

编译沿用仓库的 `g++-16`、C++23、Homebrew GSL 路径，增加 `-pthread`。
`make fd11` 只编译，不运行计算，也不改变原来的 `make main` 行为。

磁场输入为 `table/bfield_t00.txt`、`bfield_t08.txt`、`bfield_t10.txt`、
`bfield_t12.txt`、`bfield_t14.txt`、`bfield_t16.txt`，分别对应 0、0.8、1、1.2、1.4、1.6 rad。
`table/` 被 Git 忽略，换机器后需要重新准备。缺少哪些表，就用现有生成器生成哪些：

```bash
python3 py/gen_bfield.py 0
python3 py/gen_bfield.py 0.8
python3 py/gen_bfield.py 1.0
python3 py/gen_bfield.py 1.2
python3 py/gen_bfield.py 1.4
python3 py/gen_bfield.py 1.6
```

生成器需要 NumPy、SciPy、Matplotlib；使用已安装这些包的 Python 环境。
本工作区验证所用解释器为 `/opt/homebrew/Caskroom/miniforge/base/bin/python3`。
程序校验表中扭转角及方向网格，零扭转还要求 `p=1, A=C=0`。

## 参数和物理模型

```bash
build/fd11 --setup a --threads 8 --seed 42 \
  --output data/fd11_a.txt --photons 76800000
```

`--setup`、`--threads`、`--seed`、`--output` 必填，使用空格分隔参数和值。
`--photons` 默认 76800000，计数的是发射光子，包括最终被恒星吸收的光子。
默认数量对应论文每种分箱配置的总格数乘以 10000；**不保证每格实际收集到 10000 个光子**。
`--seed` 接受 0 至 18446744073709551615；线程数和光子数必须为正整数。
已有输出文件不会覆盖。父目录不存在时自动创建。

公共参数：R=10 km，Bpole=10¹⁴ G，T∞=0.4 keV，R/rs=3。
质量由 R/rs 换算，不采用 `main.cpp` 中的 1.4 倍太阳质量。
j 通过质量设为零同时关闭弯曲和红移，仍保持 T∞=0.4 keV。
双极帽等光子数发射；所有表面区域沿用 `InitFD11` 的各向同性强度采样。

经确认，动量分布采用 `PowerLaw2` 的 p⁻²，βmin=0.2，
βmax=√(1−γmax⁻²)。论文式 (7) 与正文 α 的符号不一致，此处明确选择负二次幂。
单向采用沿 +B（北向南）的电子，电荷符号 −1，电流份额 1。
双向采用沿 +B 的电子和沿 −B 的正电子，电流份额各 0.5；质量电荷比的绝对值参数均为 1。
现有接口直接以有符号 β 评价分布，不能再次按电荷符号反转速度。

两个额外开关仅可与 `--setup a` 配合，且相互排斥：

- `--single-scattering`：最多一次散射；之后仍计算光线、偏振传播和表面吸收，不能直接将散射点当作无穷远。
- `--untwisted`：使用 t00 的偶极磁场并关闭散射，保留引力和偏振演化。

全部数值精度沿用现有模块默认值，并写入文件头。旧 `deprecated/fd11_fig7.cpp` 不参与编译。

## txt 格式与复现性

格式版本 `fd11_photons_v1`，每个逃逸光子一行，浮点数使用 17 位有效数字、英文小数点：

```text
photon_id energy_inf_keV mu_k Q U V n_scatter seed_mode last_scatter_mode
```

| 列 | 含义 |
|---|---|
| photon_id | 从 0 开始的发射编号；缺失编号对应被吸收的光子 |
| energy_inf_keV | 无穷远能量，keV；保留全部能量，不截断到绘图区间 |
| mu_k | 逃逸传播方向与正磁轴夹角的余弦 |
| Q U V | 单光子的归一化 Stokes 参数，I=1 |
| n_scatter | 该光子的总散射次数 |
| seed_mode | 初始模式：O=0、E=1 |
| last_scatter_mode | 最后一次散射产生的模式：O=0、E=1；从未散射为 −1 |

`last_scatter_mode` 是散射后的模式标签，不是偏振耦合后强行判定的最终 E/O 模式。
天空基底 x 轴沿正磁轴在垂直于光线方向平面内的投影，y 轴使其与光线构成右手系。
严格沿磁轴时沿用现有代码的 +x 投影后备约定。方位角已利用轴对称性消去。

`#` 开头为元数据，包含所有模型参数、实际磁场参数、精度、随机种子和线程数。
成功尾部包含 `emitted`、`escaped`、`absorbed`、`scatterings` 和 `complete = true`。
`scatterings` 包含最终被吸收光子的散射。失败返回非零状态；未完成文件不可作为完整样本使用。
文件不能续算，也不会自动覆盖重算。

N 个计算线程包含主线程；每个线程持有独立的积分工作区和光子状态。
每个光子的随机种子为 `SplitMix64_finalizer(seed + photon_id + 0x9e3779b97f4a7c15)`，加法按 64 位无符号整数回绕。
每块 64 个光子。线程算完一块后将结果放入缓冲区，再领取下一块任务；
已连续完成的块仍按光子编号顺序写出，线程无需等待自己的块写出后才继续计算。
为限制内存，已领取但尚未写出的块最多为线程数乘以 64（包括正在计算的块）；
达到上限后暂停领取任务，待前面的块完成并写出后恢复。内存随线程数而非总光子数增长。
相同程序、环境、setup、变体、种子和光子数在不同线程数下，数据行及最终计数相同；文件头的线程数字段会不同。
跨编译器或平台不保证逐位相同。stderr 的 `completed` 包含已算完但尚未按序写出的块，`written` 是已提交的发射数。

### CPU 利用率与调度

旧调度让每个线程等待自己的块按序写出后才领取下一块；
某个光子耗时较长时，其他线程即使完成计算也会空等，可能只剩一个线程在运行。
现在通过上述有上限的结果缓冲区允许其他线程继续计算后续块。
极慢光子使缓冲区达到上限，或计算接近结束时，CPU 利用率仍可能下降。

2026-10-28 在 i7-13700KF（24 个逻辑 CPU）上使用 setup=a、seed=999、
20 线程、128000 个光子对比：旧版约 65 秒，新版约 20 秒，约加速 3.2 倍。
新版主要计算阶段的进程 CPU 占用约 1950%–1990%（单逻辑 CPU 满载记为 100%），
折合整机约 81%–83%；新旧版的数据行和最终计数完全相同。
该结果为一次短规模实测，正式运行耗时和利用率会随光子样本及机器负载变化。

论文的两组统计网格覆盖 0.04–40 keV：每十倍能量 40 格、μ 方向 64 格；
或者每十倍能量 10 格、μ 方向 256 格。同一份原始数据可以分别分箱，无需重复模拟。
各 bin 先累加 `(I,Q,U,V)=(1,Q,U,V)`，再计算线偏振度 `hypot(ΣQ,ΣU)/ΣI`、
偏振角 `atan2(ΣU,ΣQ)/2`（模 π）和有符号圆偏振 `ΣV/ΣI`。
零计数 bin 标记为空，不能把单光子的偏振角或偏振度直接平均。

不同模型的计数/Stokes 应按**发射数**归一化，不按逃逸数归一化。
Figure 8 比较单次散射试验与正常模型的一阶 E/O 强度，再按单次散射试验强度求重散射损失比例。
Figure 15、19 对每种 E 模式种子比例 f 使用
`S_mix = f*S_a/N_a + (1-f)*S_g/N_g`，f=0、0.25、0.5、0.75、1，
其中 S 是相应 bin 内的四个 Stokes 总量，N 是该模型发射总数。
必须先混合 Stokes，再计算偏振度和角度。

Figure 11 及相位采样使用

```text
mu_k(phi) = cos(theta_rot)*cos(theta_los)
          + sin(theta_rot)*sin(theta_los)*cos(phi)
```

四组 `(theta_rot, theta_los)` 为 `(45°,70°)`、`(70°,45°)`、`(60°,70°)`、`(90°,90°)`。
横轴 `phi/(2*pi)`，画两个周期时取 0–2。需要磁余纬本身时计算 `acos(mu_k)`。
Figure 10 的两个能带为 2–4 keV 和 4–12 keV；相位偏振需按论文附录将 Q/U
从磁轴投影基底旋转到自转轴投影基底。相位平均必须在该共同基底内先积分 Stokes，
然后计算偏振度/角度，不能平均各相位的偏振度或角度。
