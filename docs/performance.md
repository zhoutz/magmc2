# FD11 输运性能审查与优化

本文记录第一轮保守优化。后续的局部插值、光深误差预算和多线程实现见
[第二轮快速模式报告](performance_fast.md)。下文的逐字节一致结果对应第一轮构建，
不能当作 `--fast` 的精度承诺。

目标是 `src/fd11_fig7.cpp` 的实际批量计算。审查覆盖 `src` 的全部 18 个文件；
基线为提交 `2b95fd66bb7c70b1d36c4342e94d15d208c30dd0` 的数值算法。
两版使用相同的 GCC 16.2.0、`-O3 -DNDEBUG`、GSL、磁场表、随机种子和容差。
基线编译额外使用 `-include print`，解决当前编译器下源文件缺少 `<print>` 的问题；
优化版已显式包含该头文件。

## 已合入的计算优化

1. **延迟计算偏振插值。** `rates_at()` 先检查共振判别式、速度范围和粒子分布。
   只有存在有效通道时，才调用 Magnus dense output；同一点的两个通道共用一次
   Stokes 计算。随机数调用、非零散射率的计算公式和运算顺序保持原样。
2. **保守排除整个轨道段内的共振。** 磁场表载入后，计算所有磁纬度上磁场模的
   上下界。每个测地线步使用 dense polynomial 的区间包围估计整个轨道段的
   半径范围，包括向内传播和转向，不能只取两个端点的半径。
   只有证明该段无共振时，跳过边界搜索与光深积分；偏振仍按照原算法演化。

第二项使用必要条件

```text
x = gamma * (1 - beta * mu)
beta_limit = max(abs(b_min), abs(b_max)) < 1
edge = sqrt((1 + beta_limit) / (1 - beta_limit))
1/edge <= x <= edge
```

其中 `x = charge_mass_ratio * B_to_omega * |B| * sqrt(1-rs/r) / omega_inf`。
计算整个轨道段的 `xmin/xmax` 后，仅在它与上述必要区间完全分离时排除共振。
上下界带有浮点舍入裕量；临界区间继续执行原来的扫描与积分。
角向界基于程序实际使用的分段线性 `f/fp`，并单独处理 `mu=1` 端点。

不满足界限条件的磁场表、`beta_limit=1` 的分布（例如 Boltzmann），自动保留原有
完整积分路径。`PhotonEvolution::Options::resonance_bounds=false` 可关闭区间排除。
`BField` 被输运器按常量使用；若外部代码修改公开的 `f/fp/p/A`，须重新调用
`prepare_magnitude_bounds()` 更新缓存。

没有放宽积分容差、改变逃逸/绝热判据、修改 RNG 或使用 `-ffast-math`。
本次速度提升主要来自减少本来就为零的光深计算。

## 测量和验证

初始插桩样本：1,000 个光子，seed=110701，默认设置。
调用数不是 CPU 时间占比，插桩程序也不用于比较速度。

| 操作 | 基线调用数 |
| --- | ---: |
| 光深分段扫描 | 578,969 |
| QAGS | 1,207,286 |
| QAGS 被积函数 | 36,837,150 |
| 偏振 dense output | 30,690,736 |

基准结果由串行 A/B 运行记录；完整输出逐字节比较，包含每个光子的能量、方向、
Q/U/V、散射次数和最终计数。以下为包含程序启动和输出的墙钟时间：

| 设置 | 光子数 | 原版 | 优化版 | 加速比 | 输出 |
| --- | ---: | ---: | ---: | ---: | --- |
| seed=110701，默认，第 1 次 | 5,000 | 25.60 s | 15.76 s | 1.62× | 逐字节一致 |
| seed=110701，默认，第 2 次 | 5,000 | 26.16 s | 15.56 s | 1.68× | 逐字节一致 |
| seed=110702，默认 | 5,000 | 57.07 s | 48.75 s | 1.17× | 逐字节一致 |
| seed=110703，`--tight` | 1,000 | 9.77 s | 6.28 s | 1.55× | 逐字节一致 |

原始数值保存在 `build/performance_audit/benchmark.json`，同目录保存 A/B 光子输出。
不同种子的耗时差别很大，应继续记录单光子耗时、散射次数、Magnus 接受/拒绝步数，
分析少数慢轨迹，不能只用 seed=110701 外推百万光子生产耗时。
这种一致性只覆盖已测试样本，不能替代其他物理参数下的验证。

新增 `tests/transport_bounds.cpp` 检查生产磁场表 200,001 个角度位置、
随机轨道的半径包围、向内/转向轨道、两种速度方向、两种绝热偏振，
并验证被排除区间的实际散射率为零、无有效通道时不调用偏振插值、
不适用条件下回退到完整积分。该测试覆盖 28,196 个被排除区间、3,335 个向内步
及 108 个转向步。原有 Python 的三个分箱/偏振测试也通过。

复现：

```sh
make fd11_fig7 test-transport-bounds
python3 py/benchmark_transport.py build/performance_audit/baseline build/performance_v2/stage1 \
  --photons 5000 --seeds 110701 110702 --repeat 2
python3 py/benchmark_transport.py build/performance_audit/baseline build/performance_v2/stage1 \
  --photons 1000 --seeds 110703 --tight
```

基准脚本保存每次运行的输出、日志、墙钟时间及 `summary.json`，发生错误或结果
不同即失败。`build/performance_audit/baseline` 是本次保留的本机基线可执行文件，
与其他 `build/` 产物一样不纳入版本控制。
`build/performance_v2/stage1` 是进入第二轮前保存的第一轮可执行文件。

## 其余文件的审查结论与后续优先级

| 模块 | 发现及建议 |
| --- | --- |
| `evolution.hpp`, `find_root.hpp` | 散射点求根反复计算 `integral(a,l)`，而求根默认 `xacc=0`。下一轮可缓存累计光深，使用带括区间的反演，并让定位误差与光深误差匹配；共振合根附近必须单独处理。不要简单给所有根统一放宽容差。 |
| `quad.hpp` | 当前只有非有限结果会抛错，有限结果即使 `status != GSL_SUCCESS` 也会被接受，且丢弃 `abserr`。在尝试放宽容差之前，应记录失败状态和实际误差，采用回退或重试。此次插桩的 1,000 光子样本未出现非零状态。 |
| `magnus.hpp` | dense output 每次做两次四点插值及旋转。预计算插值多项式系数可进一步减少工作，但要检查舍入变化对自适应路径的影响。单位 Stokes 长度正确并不能保证偏振方向正确。 |
| `bfield.hpp`, `hunt.hpp` | 每次磁场求值包含两个非整数幂，均匀网格定位已是 O(1)。角向查表或插值生成元有潜力，但会改变共振位置和偏振相位，需要极区、表格节点、共振边界的误差分析。 |
| `geodesic.hpp`, `dopr5.hpp` | 测地线默认 `1e-10`，且步长上限 `0.1*r`。可以扫描容差与步长上限，但上限同时影响共振边界发现，不能只看轨道误差；需要逐项验证。 |
| `distribution.hpp` | `PowerLaw2` 已用解析归一化和均值。可将 `f(beta)` 与散射 Jacobian 的公共平方根消去，作为低优先级代数优化；不要优先恢复已注释的通用 PowerLaw。 |
| `bessel_K1_scaled.hpp` | 仅在 Boltzmann 构造时使用，FD11 不走该分布，不是本次热点。 |
| `initialize.hpp`, `ran.hpp` | Planck 数分布、发射方向和散射方向采样调用频率远低于积分；暂不更换 RNG 或采样算法。改变随机流会使逐光子比较更困难。 |
| `polarization.hpp`, `doubles.hpp` | 小型向量/坐标变换基本可内联，不宜以去掉物理有效性检查作为主要提速手段。 |
| `component.hpp`, `constants.hpp` | 参数与常数声明，没有值得单独优化的计算热点。 |
| `fd11_fig7.cpp`, `main.cpp`, Makefile | 生产目标已开启 `-O3`；`main` 目标未开启，但它只跑一个光子，不能据此估算生产加速。逐光子文本输出可以后续改为缓冲分块或二进制，先测其占比。 |

GSL QAGS 为含可积奇点的积分设计，不能将全部区间直接替换成无误差估计的固定
低阶求积。可在已确认平滑的区间试用更便宜的积分，保留奇点区间的稳健回退。
参考 [GSL 官方积分文档](https://www.gnu.org/software/gsl/doc/html/integration.html)。

已试验但未采用：跨测地线段继承 Magnus 的建议步长。同一个 5,000 光子样本
没有得到稳定提速，且最终逃逸/吸收计数发生变化，因此此次未合入。

多核运行方面，现有 `docs/fd11_fig7.md` 已使用四个独立进程；本次优化可直接用于
这些批次。其整体加速应重新实测，不能再把单核加速简单乘以四。若改为线程，
每个 worker 必须拥有独立的 PhotonEvolution/RNG/GSL workspace，GSL 的全局
错误处理器应在启动线程之前设置；复现要求高时应按光子 ID 分配稳定随机流。

若后续允许近似，建议以分能量/方向箱的 `I,Q,U,V` 和散射次数分布作验收，
保留高能尾、极区和多次散射样本。可以把数值偏差预算设为目标统计误差的一小部分，
例如 `0.1 sigma`，但必须按最终生产光子数与分箱确定；不能直接将全局
`1/sqrt(N)` 当作每个箱或偏振角的误差。
